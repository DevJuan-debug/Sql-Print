Conecta MerFresh con Supabase

La app guarda los diagramas, las cuentas y la colaboración en tiempo real en tu proyecto de Supabase.

  1. Crea un proyecto gratuito en supabase.com.
  2. En SQL Editor, pega el contenido de supabase/schema.sql y pulsa Run.
  3. En Authentication → URL Configuration, pon esta dirección como Site URL y agrega /** al final en Redirect URLs.
  4. Copia .env.example como .env y completa SUPABASE_URL y SUPABASE_ANON_KEY (Project Settings → API).
  5. Reinicia el servidor con npm start y recarga esta página.

Los pasos detallados están en el README del proyecto.

  2. Abre el SQL Editor de Supabase, pega el contenido (Ctrl+V) y pulsa Run.
  3. Vuelve aquí y pulsa Ya lo ejecuté.
